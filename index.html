NYC GPT — RAG Chatbot

A streaming AI chatbot that answers questions about New York City, grounded in retrieved Wikipedia sources.

  • RAG pipeline: scrape pages → chunk with LangChain.js → embed with OpenAI → AstraDB vector search → grounded GPT answer.
  • Answers stream token by token to the chat UI using the Vercel AI SDK.
  • Per-IP rate limiting plus message-length, history, and response-token caps to keep API cost bounded.
